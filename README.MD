# Hospital Patient Records Analysis

## Project Overview
This project analyzes hospital patient records to understand patient data and data quality.

## Tools Used
- SQL
- Microsoft Excel
- CSV Dataset

## Project Files
- Database Creation SQL Script
- Hospital Patient Dataset
- Data Quality Checks
- Analysis Queries
- Hospital Patient Records Project Report
- Findings and Recommendations

## Objective
To analyze hospital patient records, identify data quality issues, and provide useful findings and recommendations.
